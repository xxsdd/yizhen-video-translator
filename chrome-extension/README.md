# 译帧 Chrome 扩展

先双击桌面“译帧”，让本地服务运行。Chrome 打开 `chrome://extensions`，启用开发者模式，点“加载已解压的扩展程序”，选择本文件所在的 `chrome-extension` 文件夹。然后在 Chrome 的拼图菜单中将“译帧 · 一键导入视频”固定到工具栏。

在视频网页点击译帧图标：单个视频直接导入；多个候选视频显示封面和标题供勾选。没有发现视频时，先播放几秒再检测，也可以尝试导入当前网页。导入后进入译帧对应任务并等待，不自动下载。侧边点击“开始下载”，完成后点击“开始处理”识别字幕；随时可以暂停。右键可以重命名、优先处理或删除。默认最高可用画质，没有清晰度菜单。导入不调用翻译 AI。

字幕稿右键打开编辑框，也可以悬停后点铅笔或键盘 Shift+F10。原文变更只使相关句子的译文失效；其他语言的旧版本也会同步标记待更新。保存不会自动调用 AI。所有修改之前保留本地备份，编辑中若内容变化则拒绝覆盖。

本扩展使用 Chrome 官方 Manifest V3 + activeTab：只有点击时检查当前页面，没有 cookies、history、全网站常驻访问权限。访问本机服务仅允许 127.0.0.1:8765，沿用服务的同源验证，不放宽 CORS，不包含任何 API Key。

支持可见 video/source、页面已加载的 m3u8/mpd/mp4 资源、VideoObject 元数据及常见嵌入页。跨域嵌入、未播放视频、需要登录或 DRM 等情形不保证获取成功；不会把网页登录状态当作下载授权。资源地址若是一个固定清晰度的文件，仅能下载该文件；已识别的平台播放页由 yt-dlp 选择最佳音视频。Chrome 内部页面与商店页面无法检测。

参考：https://developer.chrome.com/docs/extensions/develop/concepts/activeTab
