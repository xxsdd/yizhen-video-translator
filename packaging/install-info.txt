译帧 · Windows 本地视频字幕工具

安装后双击桌面「译帧」即可打开浏览器使用，不需要手动安装 Python 或 FFmpeg。

安装包包含 CPU / NVIDIA GPU 识别运行依赖和离线英汉词典；不包含显卡驱动和语音识别模型。首次使用请在设置中选择识别设备并点击「准备模型」，模型下载需要联网和额外磁盘空间。

为兼容普通电脑，新安装默认使用 CPU。使用兼容的 NVIDIA 显卡时，可在设置里切换到 NVIDIA GPU。翻译服务需要你自己的账号或 API 设置，点击翻译才会发送请求。

视频、字幕、模型和设置保存在安装目录下的 data 文件夹中。覆盖升级不会打包或上传这些内容，卸载保留本地数据。请勿把含个人 data 文件夹的整个安装目录发给他人。

本程序未配置代码签名。下载后可使用发布页提供的 SHA256 校验文件核对完整性。
